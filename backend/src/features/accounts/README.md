# Accounts feature — US01

Den här mappen tillhör **US01: Skapa konto**.

Backendkod för kontoskapande läggs här när K01–K03 och vald backendteknik är fastställda.

Strukturen ska växa efter faktisk funktionalitet i stället för att skapa tomma routes/services för framtida user stories.

Exempel på komponenter som kan tillkomma vid behov:

- request-/route-hantering
- validering
- konto-service
- datalager
- tester

Identitetsverifiering hör till US02 och ska inte byggas in här i förväg.
