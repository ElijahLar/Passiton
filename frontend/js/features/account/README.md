# Account feature — US01

Den här mappen tillhör **US01: Skapa konto**.

Frontendkod för kontoskapande läggs här när K01–K03 har brutits ned till konkreta acceptance criteria.

Exempel på sådant som kan hamna här när kraven kräver det:

- registreringsvy/formulär
- klientvalidering
- anrop till konto-API
- fel- och laddningsstates

Skapa inte funktioner för inloggning, identitetsverifiering eller andra senare user stories här om de inte uttryckligen krävs av US01.
